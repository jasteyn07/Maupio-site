Maupio Homepage Prototype - Initial Release
===================================================

This ZIP contains the initial homepage prototype for Maupio, designed for GitHub Pages deployment.

Included:
- index.html: Main homepage layout with brand styling.
- style.css: Styles using Maupio's brand colors.
- assets/logo.png: Placeholder for your logo.
- release-notes.txt: This document.
- README.md: Quick start instructions.

To deploy:
1. Upload the contents to your GitHub repository (e.g., Maupio-site).
2. Enable GitHub Pages in repo settings -> Pages.
3. Set source to 'main' branch and root folder.
4. Access live site at: https://<your-username>.github.io/Maupio-site/

This is the first visual draft. Feedback welcome.
